# FFmpeg — aviso de componente de terceiros

A distribuição para Windows do VFL Gerador WebM Token inclui executáveis e bibliotecas do FFmpeg, executados como processos separados pelo aplicativo.

- Versão empacotada: `n8.1.3-6-gff48edd8b2-20260928`
- Pacote de origem do binário: `ffmpeg-n8.1-latest-win64-gpl-shared-8.1.zip`
- Projeto de builds: https://github.com/BtbN/FFmpeg-Builds
- Código-fonte do FFmpeg: https://github.com/FFmpeg/FFmpeg/tree/ff48edd8b2
- Site do FFmpeg: https://ffmpeg.org/

O FFmpeg é software livre distribuído separadamente sob os termos indicados em `THIRD-PARTY-FFMPEG-LICENSE.txt`. A licença do FFmpeg não é substituída pela licença do aplicativo VFL.
